
### Shell environment set up for builds. ###

You can now run 'bitbake <target>'

Images:
    az0x-image          minimal root filesystem
    az0x-image-desktop  Sato desktop with touch and an on-screen keyboard

MACHINE defaults to az01-premium (Denon DJ SC6000); set it in conf/local.conf
or on the command line, for example:
    MACHINE=az01-player bitbake az0x-image-desktop

The image to flash is tmp/deploy/images/<machine>/<image>-<machine>.rootfs.ext4.
See the meta-az0x README for staging the vendor files and for flashing.
